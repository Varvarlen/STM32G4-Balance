## 速度环带宽

PI 理论值（纯反馈路径，不计 EKF+前馈）：

```
ωn = √(Kt×Ki/J) = √(0.029×1.221/1.83e-5) = 44 rad/s = 7.0 Hz
ζ  = Kt×Kp/(2×J×ωn) = 0.79
BW_PI ≈ 1.1×ωn ≈ 7.7 Hz
```

实测从阶跃 rise=5ms 推算的有效带宽约 70 Hz，差 9×。原因：

| 路径 | 贡献 | BW 限制 |
|------|------|:--:|
| PI 闭环 | 稳态消差、低频扰动抑制 | 7.7 Hz |
| 前馈 iq_ff=T_load/Kt | 开环直通，阶跃瞬间响应 | 无（仅受电流环 1000Hz 限制） |
| EKF 观测器 | 相位超前的 speed_fb，等效带宽 ~100Hz | Q=200, R=0.1 |

PI 参数标定本身是合理的——7 Hz ωn 负责稳态精度。带宽的主要贡献来自 EKF 预测前馈（观测器增强控制），这是设计意图而非缺陷。

## 调试过程（按时间序）

### 阶段 1: FOC 频率修正

PA12 翻转测量发现 ADC DMA ISR 频率为 20kHz，而非代码注释的 10kHz。
TIM3 中心对齐模式下 TIM_TRGO_UPDATE 触发两次产生双倍触发。
HAL ADC DMA 启动后自动启用 HT 中断，需要在启动后手动禁用。

**修正:**
- `FOC_PWM_FREQ 10000→20000`, `FOC_DT` 自动从 100μs→50μs
- `INA240_EMA_SHIFT 3→4` 维持 0.8ms 时间常数
- 所有 10kHz 注释统一更新为 20kHz
- `__HAL_DMA_DISABLE_IT(&hdma_adc2, DMA_IT_HT)` 关闭半传输中断

### 阶段 2: 电流环提速

修正 FOC 频率后，电流环实际 BW 从 ~250Hz 降到 ~57Hz（dt 修正后积分速率为设计值，但过阻尼 ζ≈1.03 导致实际偏慢）。
采用零极点对消法（Ki/Kp=R/L=355）等比例缩放：Kp 5→15, Ki 1765→5295（3×）。

**结果:** Rise 6.2ms→0.35ms（-94%），BW 57→1000Hz。

初次尝试 BW~500Hz（Kp=19.2）失败——串口功能异常。原因是 FOC_DT=100μs 时代码积分速率与设计不符，修正 dt 后再测 3× 方案稳定。

### 阶段 3: EKF 参数标定

电流环提速 20× 后，EKF 参数需重新标定。设计离线扫描工具：
1. `ekf_calibrate.py` — 开遥测跑阶跃，采集 200Hz mech_angle+iq 数据
2. `ekf_scan.py` — 离线运行 EKF，扫描 Qa={50..5000}×Qt={1..50}×R={0.001..0.1}

**最优解:** Q_accel=200, Q_tload=1, R_meas=0.1。R_meas 是主导参数，Q_accel 几乎无关——电流环准确后，模型预测可靠性远超编码器测量。

RMSE 从 0.073→0.049 RPM（改善 33%）。

### 阶段 4: 增益调度演进

原始 RATIO=0.33：低速 Kp=0.015（旧满增益），50→-50 阶跃穿越调度带时增益跳变导致振荡加剧。
降为 RATIO=0.20：低速 Kp=0.009。改善了穿越行为，但 30 RPM 仍在过渡带，超调偏高。
最终 RATIO=1.0：新 EKF 已充分滤波，不需要减速压增益。全速段 Kp=0.044。

**结果:** 30 RPM OS 18.8%→6.6%，settle 41ms→3ms。代码清除 22 行。

### 阶段 5: 速度 PI 终值

基于实测确定 ωn=7Hz ζ=0.8，Kp=0.044 Ki=1.221。
BW≈8Hz，100 RPM settle=6ms，全速段超调 <7%。

### 阶段 6: 零速噪音

零速时 EKF 负载估计在静摩擦点粘滑振荡（±0.05A iq 波动→可闻噪音）。
解决方案：在 |speed_fb|<2 RPM 且 |speed_ref_ramp|<2 RPM 时，将负载前馈 iq_ff 钳位在 ±0.02A。
0.02A×0.029=0.00058 N·m，刚好补偿轴承摩擦，不触发粘滑。

## 关键教训

1. **中心对齐 TIM3 TRGO 双触发→ADC 20kHz 而非 10kHz。** 所有基于 10kHz 的参数（EMA, FOC_DT）均需修正。
2. **PI 的 dt 参数通过 PI_Step 传入，连续域行为在 dt 修正后不变。** 但离散域的抗饱和行为会变。
3. **电流环未达平台前，速度环振荡源排查应先排除电流环。** 提速后振荡从 n_cross=33 降到 10（-70%），说明旧电流环是主要瓶颈。
4. **负载前馈在零速时需限幅。** 否则 EKF 在静摩擦点形成正反馈极限环。
5. **速度环零速等同于粗位置保持。** 外力扰动时 PI 全效对抗产生啸叫是环特性，非缺陷。
