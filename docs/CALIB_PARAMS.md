# 电机校准参数

> 存储在 MCU Flash `0x0801F800` (Page 63, 2KB)，通过 `CAL` 命令进入校准模式交互生成。
> 运行时在 CLI 输入 `s` 查看当前值。若重新校准，需同步更新本文档。

## 编码器方向

| 电机 | enc_dir | 说明 |
|------|---------|------|
| M1 (TIM3, 左轮) | -1 | 编码器读数递增方向与电机正转相反 |
| M2 (TIM4, 右轮) | +1 | 编码器读数递增方向与电机正转一致 |

## VBUS 电压校准

| 参数 | 值 | 说明 |
|------|-----|------|
| slope | 0.008934 V/LSB | ADC 采样 → 实际电压线性斜率 |
| offset | 0.613 V | 零电流截距 |

校准公式：`VBUS = ADC_value × slope + offset`
