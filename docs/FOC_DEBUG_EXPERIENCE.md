# FOC 调试经验

## 最终 M2 工作配置

| 参数 | M1 | M2 |
|------|:--:|:--:|
| enc_direction | -1 | +1 |
| PWM 映射 | 原始 A-B-C | A/C 交换 (ch_a↔ch_c) |
| 电流传感器映射 | A/B (MOTOR1_W/U) | 交换 (ch_u=MOTOR2_W, ch_v=MOTOR2_U) |
| phase_comp | 0° | 0° |
| PI (Kp/Ki) | 0.5/20 | 0.5/20 |

等效效果：M2 经 PWM 交换 + 传感器交换后，Clarke 输入端恰好为标准 A/B 相序，与 M1 一致。

## INA240 关键陷阱

**枚举顺序必须匹配 ADC 扫描顺序。** ADC 扫描由 CubeMX 配置的 Rank 决定，INA240 枚举的整数值直接用作 `filtered_buffer` 的索引。两侧不一致会导致每个电机读到对方的电流传感器。

### 验证方法

查看 `adc.c` 中 `MX_ADC2_Init()` 的 Rank 1-4 对应哪个 `ADC_CHANNEL`，确保枚举顺序与此一致。本项目中实际扫描顺序为 IN13, IN3, IN5, IN12，对应枚举：

```c
typedef enum {
    INA240_MOTOR1_U = 0,    // IN13 = rank1
    INA240_MOTOR1_W = 1,    // IN3  = rank2
    INA240_MOTOR2_U = 2,    // IN5  = rank3
    INA240_MOTOR2_W = 3,    // IN12 = rank4
} INA240_Channel_t;
```

**教训**：不要假设扫描顺序，必须从 `adc.c` 代码中确认 Rank 分配。

## 实验体系

五个独立实验，每个解决一个独立变量。顺序执行可系统性地完成新电机的 FOC 适配。

### 实验 A：编码器方向校准

**目的**：确定 `enc_direction`（+1 或 -1）。

**方法**：`enc_direction` 设为中性值 {1,1}，用手转动电机，观察 raw_angle 变化。正转时 raw 递增 → +1，递减 → -1。

**关键代码** (`TaskEncoderCalib`)：读取 `g_enc[i].raw_angle`，与上一帧差分计算变化方向。输出原始角度和 RPM，只依赖编码器硬件，不受 PWM/电流传感器配置影响。

**经验**：raw_angle 是 14-bit 无符号整数 (0-16383)，无符号歧义。RPM 有符号，直观。正转 → 正 RPM 是我们定义的符号约定。

### 实验 B：开环相序标定

**目的**：判断三相线是否交叉。

**方法**：施加相同的旋转电压矢量 `Vα=Vm·sin(θ), Vβ=-Vm·cos(θ)` 给两台电机，观察 RPM 方向。同向 = 相序一致，反向 = 其中一台有交叉。

**关键代码** (`TaskPhaseWireCalib`)：开环 SVPWM 输出，电压频率 1Hz，Vm=2V。测量 RPM 不依赖电流传感器，结果不受 INA240 配置影响。

**经验**：此实验只判断相序是否交换，不判断交换的是哪一对。需结合电流传感器映射实验确定具体交换方案。

### 实验 C：电流传感器-相线映射

**目的**：确认每个 INA240 通道连接在哪个电机相上。

**方法**：逐相施加 DC 激励（占空比 58%，~0.6V），观察 4 个 INA240 通道的电流响应。电流为正的通道 = 该相上的传感器。

**关键代码** (`TaskCurrentSensorMap`)：`Motor_SetDuty` 直接控制单相占空比，循环遍历 2 电机 × 3 相共 6 组。逐相激励约 5 秒便于观察。

**经验**：此实验依赖 INA240 枚举正确。如果枚举和 ADC 扫描顺序不一致（见上文陷阱），结果全部作废。

### 实验 D：DC 锁轴 phase_comp 标定

**目的**：测量编码器零位与电机 d 轴的偏移角，直接得出 `phase_comp`。

**方法**：施加 DC 电压 `Vα=Vm, Vβ=0`（A 相激励）锁住转子。电机 d 轴对齐到 A 相 (0°电角)。读取编码器角度，归一化到 [0,2π)。`phase_comp = -avg_elec`。

**关键代码** (`TaskPhaseCompCalib`)：Vm=5V 强锁，2 秒稳定，100 次采样取平均。

**经验**：
- 7 极对电机在 1 个机械圆周内有 7 个稳定点，电气角度相同 (mod 2π)。
- 需足够锁紧力（电压不能太低），否则摩擦导致每次锁定位置有偏差。
- **不要用手转动电机后重新执行**，7 个稳定点电气角相同，但摩擦会导致不一致。

### 实验 E：PWM 交换全遍历

**目的**：如果前序实验无法确定正确的 PWM 映射，遍历所有可能。

**方法**：开环 q 轴电压驱动，遍历 4 种 PWM 交换 (原始、B/C、A/B、A/C)，测量 Id/Iq。Id≈0 的配置为正确。

**关键代码** (`TaskPWMSwapTest`)：直接计算占空比并按交换方式排列后调用 `Motor_SetDuty`，每 3 秒切换一组。

**经验**：Id≈0 但电机不转 = d/q 轴可能交换（须结合 phase_comp 扫描确认）。

## PI 参数调优

电机电气时间常数极小 (R=6.5Ω, L≈50μH → L/R≈7.7μs)，远快于 PWM 周期 (100μs)。Ki 过大时积分快速积累导致 Vq 饱和。

**推荐起步值**：Kp=0.5, Ki=2~5。稳定后逐步增大至 20。

## FOC 电流环验证

用手抓住旋转中的电机轴：
- 电机被迫减速 → 反电动势下降 → Vq 自动退饱和
- Iq 仍稳定跟踪设定值、Id≈0 → 电流环正常
- Vq 在高速时饱和 (≈Vbus) 是反电动势补偿的**正常行为**，不是故障

## 常见故障症状速查

| 症状 | 可能原因 |
|------|------|
| 静止时 Iq 跟踪，转动后振荡/饱和 | enc_direction 符号错误 |
| Id/Iq 以电频率 2ω 振荡 | Park 参考系反转 (encoder 方向错) |
| Id 很大，电机锁死 | phase_comp 偏移约 90° |
| Iq 跟踪，电机不转 | d/q 轴交换 (传感器相序错) |
| 所有 phase_comp 下电机均不转 | PWM 通道映射有误 或 电流传感器错位 |
| 两电机中只有一台正常 | 检查该电机的 enc_dir / PWM / 传感器 三条独立路径 |
