# 电机参数

## 测量方法

| 参数 | 测量方法 | 日期 |
|------|---------|------|
| R | 校准模式四线法 (CALIB_MotorParams) | — |
| Kt | 示波器反电动势 (手动拧轴, 5组平均) | 2026-05-12 |
| Kt/J | 恒流加速 + 自由减速 + 示波器交叉验证 | 2026-05-12 |
| J | Kt / (Kt/J) 间接计算 | 2026-05-12 |
| L | 阶跃测试 + 指数拟合 (闭环 τ_eff × (R+Kp)) | 2026-05-12 |
| T_fric | 自由减速分析 J × (T_fric/J) | 2026-05-12 |
| enc_dir | 校准模式编码器方向 (CALIB_EncoderDir) | — |
| phase_comp | 校准模式编码器偏置 (CALIB_EncoderOffset) | — |
